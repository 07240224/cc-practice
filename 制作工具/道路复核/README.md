# R5 俯视道路核对工具

本工具单独生成 `道路俯视复核R5`，不读取V4道路中心线，也不修改可玩地图。初始用户图与后续批注决定布局；校方2023高清图辅助提取原色路面，2020校方图交叉核对。网络图片不标作用户原附件。

在项目虚拟环境安装本目录 requirements.txt，然后从任意 cwd 调用本目录两个脚本，先“提取原色路面.py”，再“生成俯视核对图.py”。路径以仓库根目录为准。输入为 R5 目录中的高清参考图及原占地参考数据，字体用仓库 `制作工具/fonts`。

分类原则：保留所有原色白面、明确浅色铺装、独立碎段；按最大实际宽度单列极细对象，不按面积小删路；建筑内孤立白块可排除，架空连廊下T形地面面必须保留。绿叶街按实际格砖色及边缘提取，不整块涂白。字样遮挡仅局部恢复底色。核对页分别呈现参考路面、连廊下通行、前次红补蓝删，供用户确认。

不使用道路闭运算、统一宽度中心线重画或RDP简化。全分辨率透明面、JSON边界、排除清单及来源随稿保存。三角绿岛的三边闭合、两侧廊下接续、绿叶街东端凸口和111号文字区域是本轮专项复核项。
